# BBC News Category Predictor

An NLP-powered news classification system built using:

* NLTK
* TF-IDF Vectorization
* K-Nearest Neighbors (KNN)
* Streamlit

## 🚀 Live Application

https://bbc-news-category-predictor-mrv8evrcrwa675s33yujjw.streamlit.app/

## Categories

* Business
* Entertainment
* Politics
* Sport
* Tech

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
